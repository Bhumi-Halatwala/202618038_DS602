# Statistical Modeling with Python

> A curated collection of applied statistics and data science work completed as part of the **M.Sc. Data Science** curriculum. This repository houses lab assignments, analytical notebooks, and interactive dashboards built throughout the course.

---

## 📌 About

This repository serves as a working archive for coursework in **Statistical Modeling with Python**. Each project within the repo demonstrates an end-to-end analytical workflow — from raw data exploration and formal hypothesis testing, through regression modeling and diagnostic validation, to the delivery of interactive tools.

The emphasis is on **rigorous statistical reasoning** combined with **real-world software delivery**, not just static analysis.

---

## 🎯 Scope

Work included here spans the following areas:

- **Exploratory Data Analysis** — descriptive statistics, distributional analysis, correlation studies, and visual diagnostics.
- **Hypothesis Testing** — parametric and non-parametric inference with formal assumption checks (normality, variance, independence).
- **Regression Modeling** — Ordinary Least Squares and related techniques via `statsmodels` and `scikit-learn`.
- **Model Diagnostics** — residual analysis, multicollinearity checks, heteroscedasticity tests, and goodness-of-fit evaluation.
- **Interactive Delivery** — building and deploying data-driven web dashboards using Streamlit and Plotly.
